# kamelchuk.org.ua

Сайт команди Юрія Камельчука: збір заявок до команди (вибори та проєкти), ідеї, цінності, документи «Української Нації». Astro + Cloudflare, українська (`/`) та англійська (`/en/`) версії. Стиль поки як у kamelchuk.org; дизайн переробляємо за референсами.

Бриф: Google Doc «02 Бриф — kamelchuk.org.ua». Тексти документів: Google Doc «Документи УН» (папка «Брифи сайтів екосистеми» на Drive).

## Розробка

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # статичний сайт у dist/
```

## Структура

- `src/data/site.ts` — контакти, штаби (мапа), 5 стовпів, статуси, проєкти, організації, цілі донатів.
- `src/i18n.ts` — адреси сторінок і меню.
- `src/content/docs/uk/*.md` — документи УН дослівно. `hidden: true` — не публікується (зараз: «План розвитку партії на рік»).
- `src/content/news/{uk,en}/*.md` — новини кампанії (поле `pillar` — один із 5 стовпів, `key` пов'язує UA/EN).
- `src/views/*.astro` — сторінки (одна view на обидві мови), `src/pages/` — маршрути.
- `functions/api/join.ts` — прийом заявок «Долучитися».

## Заявки

`POST /api/join` присвоює номер `K{n}-{місяць}-{рік}`, зберігає в KV `JOINS` і розсилає:

| Канал | Змінні середовища Cloudflare |
|---|---|
| Telegram-бот (Юлія Бондар, Олег) | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_IDS` |
| Google Таблиця | `SHEETS_WEBHOOK_URL` |
| Email команді + лист заявнику з документами | `RESEND_API_KEY`, `MAIL_FROM`, `MAIL_TO` |
| Запрошення до чату команди в листі | `TEAM_CHAT_URL` |

## До запуску

- Реквізити рахунків для «Підтримати» (кнопка оплати вимкнена).
- Система відбору до команди, прізвище Олега, чат команди.
- Документ 14 «План проведення виборів УН до ВР».
- Англійські переклади документів.
- Прибрати `noindex` у `src/layouts/Base.astro`, підключити домен.
