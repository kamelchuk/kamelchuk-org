## І. СИЛА (Безпека та Національна суб’єктність)

1. Запуск ВПК 2.0: Створення консорціумів з міжнародними партнерами для спільного виробництва дронів, систем РЕБ та ракет.

2. Захист критичної інфраструктури: Посилення кібер-підрозділів для захисту енергомереж та цифрових баз даних.

3. Модернізація кордону: Повне технічне переоснащення системи контролю державного кордону (системи спостереження та моніторингу).

4. Комплексна програма реабілітації ветеранів: Запуск персональних планів реінтеграції (навчання, працевлаштування, бізнес).

5. Національний культурний фонд: Запуск грантових програм для україноцентричного кінематографа, книговидання та популяризації традицій.

## ІІ. ЗАКОН (Справедливість та Інституції)

1. Антикорупційний аудит: Проведення повного аудиту державних компаній та установ з подальшою публікацією результатів та притягненням до відповідальності.

2. Цифровізація послуг: Переведення 100% базових адміністративних послуг у цифровий формат (Держава у смартфоні), усунення прямого контакту з чиновником.

3. Старт судової реформи: Запровадження механізмів формування суду присяжних для резонансних справ.

4. Фінансова децентралізація: Законодавче закріплення повної фінансової автономії громад (збільшення частки податків, що залишаються на місцях).

5. Створення «Ради Совісті»: Формування дорадчого органу зі 100+ моральних авторитетів для незалежного моніторингу реформ.

## ІІІ. РОЗВИТОК (Економіка, Соціум, Інновації)

1. Створення Вільних економічних зон (ВЕЗ): Запуск пілотних ВЕЗ з 0% податком на прибуток для інноваційних виробництв.

2. Старт «Економічного паспорта»: Запровадження системи накопичувальних рахунків для громадян як співвласників багатств держави.

3. Лібералізація податків: Впровадження податку на виведений капітал замість податку на прибуток для стимулювання реінвестування.

4. Платформа «Startlist»: Запуск державної інвестиційної платформи для прямого фінансування українських стартапів.

5. Житло в розстрочку для ВПО та молоді: Запуск державної програми придбання житла на пільгових умовах.

6. Зелений перехід: Надання пільгових кредитів на встановлення систем відновлюваної енергетики для домогосподарств та бізнесу.

7. Освітня реформа: Оновлення програм шкільної освіти з акцентом на STEM, критичне мислення та підприємництво.

8. Медична реформа: Перехід до моделі страхової медицини (залучення приватного капіталу до системи послуг).

9. Стипендії для талановитої молоді: Запуск програми оплачуваного навчання за кордоном з умовою повернення на державну службу або до національного сектору економіки.

10. Соціальні центри нового типу: Створення мережі пансіонатів для літніх людей та центрів підтримки для вразливих верств населення.
